# scireason-synthetic-v1

Original procedural English-language data, generated by `src/scireason/data.py`.
No external dataset, clinical record, employer material, or private evaluation task
was used. Generated problem instances and labels are dedicated under CC0-1.0;
original generator code is MIT. Model weights retain the Qwen Apache-2.0 licence.
Reference: https://creativecommons.org/publicdomain/zero/1.0/ .

The goal is a small controlled engineering study, not a comprehensive science benchmark.
Training: six families × 48 = 288. Validation: six × 8 = 48.
Test and final: ten families × 12 = 120 each. Manifest includes exact SHA-256 hashes.
Every family is balanced by count. Difficulty is single-step arithmetic or elementary
evidence logic; OOD introduces conditional probability, repeated halving, missing
variance, and invalid population extrapolation. None are neuroscience discoveries.

Train, validation and ID evaluation have different wordings. Underlying operations
are deliberately shared for ID generalisation. OOD families are completely absent
from training; OOD test and final reuse wording, so final is only numerical-instance
replication. Split-specific RNG streams and duplicate prompt hashes prevent exact
prompt overlap. They do not eliminate semantic similarity or pretraining contamination.

All preferences are synthetic oracle preferences, not human feedback. The rejected
answer is a perturbed number, invented number for missing information, or reversed
support label. Chosen and rejected use the same JSON schema. They do not model the
full range of natural model mistakes; a reward model may learn surface regularities.
DPO and RM intentionally use the same training pairs for a controlled comparison.

Numeric truth is stored at full Python precision; chosen responses round to six
places. Grading uses absolute and relative tolerance 1e-3. Missing duration and
missing dispersion require explicit null/true abstention. Evidence questions instead
require supported/unsupported, with abstain=false. Absence of causal evidence means
the causal claim is unsupported, not that the causal effect is proven absent.

No LLM judge is used. The unsupported assertion metric only covers explicit binary
claim judgements. MAE excludes unparseable answers, and must be read with coverage.
Malformed JSON counts as failure in primary accuracy. No confidence calibration is
estimated, and no medical, general intelligence or real-world reliability claim follows.
